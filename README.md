# Overview
- This is a showcase of the many various scripts I've written for my current game project. Of course, scripts are not indicative of what the game is like, only the programmed behavior!
- Most of these scripts mean something, but some were created as a result of my stubborn refusal to drag things into the inspector. Maybe like 3 of them.

# The Game
This game is designed to be a boss rush game in the difficulty and style of Cuphead. Most movement mechanics were borrowed from Cuphead. This project started so I can create something, and also because I was thinking I could make something like it conceptually, so I took a crack at it. I think I did a good job, but let's see what everyone else says!

# Features
- A basic main menu.
- 4 unique weapon types (Ice, Fire, Gem, Light). The way they all work is different. The balancing is questionable, but that's fine for now.
- Supermoves/Energy - The player can unleash advanced attacks if they damage enemies.
- Four complete mostly bug-free levels, of probably challenging experiences.
- A tutorial level that absolutely does not prepare the player, but it will teach them the basic features of the game. Also, it has a punchable training dummy!
- Basic UI.
- An "artstyle".
- Solid enough controls, that all function as intended. You may still find a little weirdness, but generally when you click buttons they do what you want.
