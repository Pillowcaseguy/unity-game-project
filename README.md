# Overview
- This is a showcase of the many various scripts I've written for my current game project. Of course, scripts are not indicative of what the game is like, only the programmed behavior!
- Most of these scripts mean something, but some were created as a result of my stubborn refusal to drag things into the inspector.

# The Game
This game is designed to be a boss rush game in the difficulty and style of Cuphead. Most movement mechanics were borrowed from Cuphead. This project started so I can create something, and also because I was thinking I could make something like Cuphead conceptually, so I took a crack at it. I think I did a good job, but let's see what everyone else says!
